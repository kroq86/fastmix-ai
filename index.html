FastMix AI

A real-time multi-track mixer and DSP engine, driven directly by an AI agent through a deterministic measure → change → measure → commit/rollback feedback loop — not remote-controlled through a GUI automation layer bolted onto a human-first DAW.

View on GitHub Quick start

Why

Getting an AI agent to mix or master inside a conventional DAW today usually means scripting the GUI, rendering to a file, reopening it, and hoping the agent can infer what changed from a waveform screenshot — a slow, lossy, render-reopen round trip. There's no structured way for the agent to know what a parameter change actually did to the sound, compare the same slice of audio before and after, or safely roll back a change that didn't work.

FastMix AI inverts that: the primary interface is the API. Every mixing/mastering operation follows the same shape:

fix a frame range → measure baseline (peak, RMS, gain reduction, spectral bands, loudness) → change exactly one parameter → measure the SAME range again → check the result against explicit technical constraints → commit, or roll back automatically

vs. Reaper + an MCP server

You can wire an MCP server up to Reaper's ReaScript API today, and it genuinely gives an agent remote control. The honest comparison isn't "Reaper can't be automated" — it's what's built into the protocol vs. what you'd have to build yourself on top of it.

Reaper + MCP gives an agent remote control. FastMix AI gives an agent remote control plus a typed, deterministic feedback loop as part of the protocol itself — at the cost of being nowhere near Reaper as a general-purpose DAW.

What's actually in it

  • Real-time mixermute/solo/pan/volume, per-track meters that are actually per-track.
  • Real DSP insertsparametric EQ, compressor, sidechain compressor, delay, sample-peak limiter, Mid/Side stereo width — on tracks, buses, and master.
  • Bus routingpre/post-fader sends, per-bus FX chains, bus mute/solo.
  • Deterministic analysismeasure/audition re-derive an exact frame range independent of live playback state.
  • Bounded assess-and-adjust workflowsone per effect type — measure, change one parameter, re-measure, commit or roll back, every time.
  • Causality envelopeoperation_id, revision_before/revision, applied_at_audio_frame on every mutating command.
  • Mix session preflighta read-only integrity gate before higher-level mix assistance runs.
  • Loudness/delivery QCfrom-scratch ITU-R BS.1770 / EBU R128-style loudness, true-peak, delivery validation.
  • MCP bridgethe full command surface exposed as MCP tools for any MCP-capable agent.
